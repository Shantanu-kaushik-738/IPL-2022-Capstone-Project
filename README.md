IPL 2022 Data Analysis
Overview

This project presents an exploratory data analysis of Indian Premier League (IPL) 2022 match-level data. The objective is to analyze match outcomes, team performance, toss decisions, player contributions, bowling performances, and venue-level trends using Python.

The analysis follows a structured data analytics workflow, including data inspection, preprocessing, aggregation, visualization, and insight generation.

Objectives

The key objectives of this project are to:

Analyze team-wise match victories.
Examine toss-winning and toss-decision patterns.
Measure the relationship between toss winners and match winners.
Compare matches won by runs and wickets.
Identify players with the highest number of Player of the Match awards.
Analyze top batting performances.
Identify notable bowling performances.
Analyze match distribution across venues.
Determine the highest winning margin by runs.
Identify the highest individual score.
Identify the best bowling figures.
